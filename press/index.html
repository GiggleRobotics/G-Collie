短文案

离开工位，也能接着看电脑上的 Agent 在做什么。用 G-Collie 在手机或浏览器打开原有会话，查看进展，也能在支持的会话里补一句要求。任务继续在自己的电脑上运行。

长文案

电脑上的 Agent 跑到哪一步了？打开 G-Collie · Agent 会话控制台，从手机或浏览器选中原来的会话，就能看到历史消息、工具调用和会话里引用的文件。碰到需要补充的细节，可以在支持的会话里直接发消息。任务仍由原来那台电脑执行。

G-Collie 支持 Codex、Hermes 和 Claude Code。Codex 和 Hermes 的控制能力取决于本机接口和会话状态。Claude Code 的外部终端记录可查看，通过 G-Collie 创建的 Claude Code 会话还可以继续发送或停止当前轮。手机一次可以配对多台电脑，每台电脑单独管理设备授权。

目前公开版提供 Linux amd64 安装包（电脑服务和网页 0.3.35），以及 Android 0.1.51。先在运行 Agent 的电脑安装服务，再用手机配对连接。
