# 用量统计

在侧栏进入“用量统计”，选择 Codex 或 Hermes。页面每分钟自动刷新，也可手动刷新。首次读取历史日志可能需要等待。

## Codex

- **账号总览**：通过 Codex 官方 `account/usage/read` 获取账号累计、单日最高、每日 Token；按上游返回的日期汇总每月。上游未返回今天时显示“未返回”，不会补成 0。本月数字为上游已返回日期之和，可能延迟。
- **账号额度**：通过电脑桌面接口读取账号真实使用百分比、窗口长度与重置时间。显示实际返回的 5 小时、每周等窗口，缺失窗口标记未返回，不由 Token 数推算额度。
- **本机明细**：解析本机 Codex 日志，显示今日、本月、已解析累计，以及每日、每月、项目、会话、模型。包含归档及子会话。项目归属采用当前本机项目关联。
- 现代日志按 `response_id` 去重；兼容旧累计 Token 日志，使用增量，避免将每个累计快照相加。缺失的历史时间归入“历史未分日”。
- 缺少日志的数据库总 Token 快照另列，不加入已解析累计，也不分摊到某天。此时项目/会话明细不完整。
- 账号与本机统计的范围、保留期限、日期口径可能不同，不混合相加。本机明细不代表账号账单。

## Hermes / DeepSeek

本机数据库可提供会话累计、普通输入、缓存读取/写入、输出、推理、API 调用数、模型计数、项目关联和部分费用估算。

Hermes 的标准计数中，普通输入不含缓存。页面输入为普通输入 + 缓存读取 + 缓存写入，总 Token 为输入 + 输出；推理包含在输出中，不额外相加。模型统计使用 `session_model_usage`，可包含模型切换和辅助请求，范围不一定等同于会话累计。

旧数据库仅保留累计值及首次/最后活动时间，无法可靠还原历史每日消耗。首次建立索引时将既有计数保存为基线，此后每分钟记录累计差值。日/月卡片明确标为“采集值”，跨日离线的增量按发现日期记录；旧累计仍保留为“历史未分日”。

费用采用 Hermes 保存的历史估算及状态，明确标记 USD 和估算范围。未知会话费用不补零，不按当前单价回算历史，不代表 DeepSeek 账单。DeepSeek 余额、套餐额度未接入，不显示虚构的周/5 小时额度。

## 数据与网络

私有索引保存在电脑数据目录 `usage-index.json`（权限 600），仅含会话标识、计数与日期，不包含对话正文和 API 密钥。读取源数据库采用只读连接。

账号请求需要电脑能访问 OpenAI。安装/打开电脑服务时，若启动环境存在代理，安装器会将 HTTP_PROXY、HTTPS_PROXY、ALL_PROXY、NO_PROXY 等代理变量保存到权限 600 的 `codex-network-env.json`，仅供 Codex 子进程使用；既有进程环境优先。代理配置不经用量接口返回，不打包进安装包。

参考：[Codex 官方接口](https://learn.chatgpt.com/docs/app-server)、[DeepSeek 缓存说明](https://api-docs.deepseek.com/zh-cn/guides/kv_cache/)。
