## 文档边界

- `docs/开发/`：需求、原型、工作进度与版本计划，供开发与验收使用。
- `docs/`：统一文档入口；根目录保留现有使用手册，`品牌/` 存放品牌资料。部分手册早于 Flutter 版本，需按客户端和日期辨别。
- [Flutter 说明](../../flutter_client/README.md)、[历次验证](../../flutter_client/VALIDATION.md)：实现边界和历史验证证据。
- [发布说明](../../RELEASE.md)、[测试记录](../../TESTING.md)：现有发布及历史测试资料。

“已实现”只说明代码或现有资料支持该能力；“历史验证通过”引用既有记录，不代表此次重新运行测试。下一版范围、视觉稿和正式发布日期均未确定。
