## 产品与版本

G-Collie 是单人自托管的移动端 Agent 工作台：电脑执行任务，手机查看和控制原来的会话。当前主体验是 Flutter Android 客户端，电脑端 Node.js 服务连接 Codex、Hermes 和 Claude Code；仓库仍保留 React Web 与旧 Android 客户端。
