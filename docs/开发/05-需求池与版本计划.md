## 待开发与补齐

### CODEX-01：定时新建聊天不依赖旧聊天上下文

- 记录日期：2026-10-26，用户要求登记，后续再继续优化。
- 当前问题：默认新建定时任务通过桌面工具接口创建会话，需要携带已保存的来源聊天 ID；虽然不经过该聊天模型代发，但仍存在来源上下文依赖。
- 目标：默认新建任务由电脑服务直接调用 Codex app-server 的 `thread/start` 创建独立聊天，再以 `turn/start` 发送用户填写的首条消息，不依赖任何旧聊天 ID 或让其他聊天代发。
- 待验证：新聊天持久化、桌面及手机列表可见、标题与无项目归属、后续继续对话和停止操作；登录状态与现有桌面账号的一致性。
- 实现约束：保留设备授权、额度检查、幂等与结果未知不重放机制；直接链路仍需有效登录及电脑服务在线。选择已有会话的发送行为另行核查，不在本条中默认变更。
- 状态：已加入需求池，待后续优化；本次未切换发送链路。

### OBS-01：补齐运行与连接日志及时间段诊断包

- 来源：2026-10-24 手机持续重连反馈，缺少当时手机及内置网络日志，原因尚未确认。
- 待完成：内置网络建立、断开、重试与恢复事件；手机前后台及启动生命周期；两端请求关联；任意时间段选择及诊断包附件。
- 要求：日志落盘、容量/时间轮转，导出脱敏，不含密钥、Cookie、配对码、正文及附件内容。
- 验收条件：模拟网络不可达、内置网络失败、超时及接口异常时能区分层级；重启可回溯，指定时段可还原重连过程；证据不足时明确说明。
- 状态：部分功能已交付，以上剩余范围待补齐；现有诊断与有限请求日志见版本记录。
