### MEDIA-01：所有会话视频直接在 App 内显示与播放

- 目标：Codex、Hermes、Claude Code 会话中，用户发送和助手返回的视频均在消息内显示视频卡片／封面，可在 App 内播放，不仅显示路径或下载文字，不跳转系统浏览器。
- 范围：核对三助手当前及历史消息的视频附件、资源引用与视频链接识别；点击消息内视频可原位播放或进入 App 内播放器，全屏后可回到原会话。具体格式和编码支持在技术核查后明确，不先承诺任意外站页面均可提取直链。
- 交互：提供播放、暂停、进度及全屏；区分加载中、播放失败、文件不存在、电脑离线、权限失效和格式暂不支持，失败可重试。已下载视频的离线播放与 FILE-01 / CACHE-01 衔接。
- 验收：三助手分别验证上传／返回视频、文字视频混排、多视频、历史重进及切换会话；视频在 App 内可见可播，返回保留会话位置与草稿；验证窄屏、横屏、深浅主题及错误恢复。未下载资源离线时提示准确；配对电脑的资源授权沿用现有边界。
- 状态：消息内视频卡片与 App 内播放已开发部署；资源 Range／授权回归通过，原视频格式／多视频／全屏真机专项待验收。

### BUG-18：Codex 额度耗尽提示与用量更新缺失

- 现象：电脑上 Codex 额度用完后，手机进入会话未出现额度用尽提示，用量统计也未收到相应更新。
- 初步定位：账号额度查询失败会转为空 limits 并保留 limitsError，手机未处理该字段而可能隐藏提示；额度与账号 Token 查询互相等待，失败结果亦被缓存。发送失败仅部分路径会补查额度。历史额度响应体未留存，不能认定已复原当时全部原因。
- 待实现：会话和用量页统一额度状态，区分正常、耗尽、未知、登录失效和查询失败；进入会话、前台恢复及手动刷新及时更新，保留最近有效数据与时间且明确过期，禁止以空数据当作正常或 0%。额度与 Token 数据分别显示状态；避免重复请求和自动重发消息。
- 验收：电脑用尽 5 小时／每周额度后手机进入会话即能检测并展示窗口及恢复时间；用量页数据一致；查询失败可见可重试；恢复额度后解除发送限制且保留草稿。明确账号额度与本机 Token 统计的不同口径。
- 待确认语义：“用量统计收不到消息”当前按额度／Token 数据未更新登记；如果指系统通知或会话消息，需进一步确认具体入口，不把该歧义当作已定位。
- 状态：查询隔离、失败分类与可见提示、前台刷新及用量定时刷新已开发部署，真实额度耗尽／恢复待用户专项验收。
