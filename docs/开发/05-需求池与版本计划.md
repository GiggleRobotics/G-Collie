- 验收：超过 200、1000 条的会话均能回溯至最早记录，图片、视频及工具记录正确；重进、刷新、切换会话、离线缓存和跳到底部行为准确；正常会话不显示该整行及空占位，离线／真实故障保留必要提示。手机、网页与原型同步核对。

### CACHE-01 补充：图片／视频关闭应用后的持久缓存（2026-11-04）

- 来源：用户反馈图片和视频似乎每次重新加载，关闭程序后不保留。状态：已核查现状，待优化／真机验收；本轮登记，不表示正式端已修复。
- 当前实现：图片保存在应用 filesDir 的 offline-images，单文件上限 8 MB、总量约 50 MB；但联网时仍优先请求，失败后才回退本地，远程 URL 图片另走网络组件。视频封面只在组件中持有 Future，播放依赖在线预览地址，没有持久视频缓存。关闭应用不应主动删除已落盘图片，实际淘汰、来源路径变化等触发原因需核对。
- 预期：已查看图片及视频封面优先本地命中，退出、强制结束和重启手机后仍能展示；仅首次、失效、内容变化或用户清理后重取。缓存按稳定电脑身份、会话及资源隔离，不能因临时网关／预览票据变化无故失效，不缓存过期访问票据替代资源身份。
- 视频：封面与完整视频分开管理；正常播放支持有上限的磁盘缓存／已缓冲内容复用，明确完整下载后可离线播放。未完整缓存的视频不能承诺离线播放，不自动下载全会话视频；提供下载、用量及清理入口，清理不删除源文件和用户草稿。
- 验收：分别核对图片、封面、部分播放视频、完整缓存／下载视频；在线重开、断网重开、强制结束、重启、电脑切换与容量淘汰；记录本地命中和实际网络请求次数，防止仅靠内存 Future 命中声称持久缓存通过。

### BUG-18：Codex 额度耗尽提示与用量更新缺失

- 现象：电脑上 Codex 额度用完后，手机进入会话未出现额度用尽提示，用量统计也未收到相应更新。

- 待实现：会话和用量页统一额度状态，区分正常、耗尽、未知、登录失效和查询失败；进入会话、前台恢复及手动刷新及时更新，保留最近有效数据与时间且明确过期，禁止以空数据当作正常或 0%。额度与 Token 数据分别显示状态；避免重复请求和自动重发消息。
- 验收：电脑用尽 5 小时／每周额度后手机进入会话即能检测并展示窗口及恢复时间；用量页数据一致；查询失败可见可重试；恢复额度后解除发送限制且保留草稿。明确账号额度与本机 Token 统计的不同口径。

- 手机入口：提供“导出诊断日志”和“上传到已配对电脑”；连接失败期间仍在手机本地保存日志，断网时可先导出，恢复连接后由用户触发上传。
