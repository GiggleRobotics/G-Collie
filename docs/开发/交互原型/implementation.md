# 原型落地说明

2026-10-24。正式实现位于 `flutter_client/lib`，电脑服务位于 `server`；不包含自动安装、重启服务或正式发布。

- 会话筛选的助手卡片改为两列；首页未选会话时隐藏输入框；用量页提供返回会话。
- 首次配对页显式填写电脑地址、六位码和可选手机名称。已有凭证时先进入工作台，在后台验证连接；失效授权才回到配对。添加新电脑可以取消并返回原电脑。
- `computers.dart` 保存电脑列表、最近选择和角色，沿用每个地址独立的安全存储凭证。切换不注销旧电脑。当前电脑可重连并访问原有连接诊断设置。
- 工作台以电脑地址隔离缓存，保存会话列表、项目及最近十个已查看会话的详情。离线仅查看，不启用发送。连接状态始终显示在固定高度标题栏。
- `quota_notice.dart` 从 `/api/usage/limits` 获取真实账号窗口，缺失的数据不补模拟值；只显示真实五小时和每周限额、剩余比例及重置倒计时。重置复用已有确认、账号校验与幂等业务。额度不足时禁止发送并保留草稿；执行中的停止操作仍保留。
- 桌面发送因状态未同步失败时，服务端再查真实额度。仅实际耗尽时返回 429 额度错误，其余保留同步异常。
- `upgrade.dart` 在 App 内 WebView 打开官方 ChatGPT 方案页面，不传递电脑凭证、不拉起外部浏览器。官方登录、支付和升级后限额同步仍需真机验收；拒绝 WebView 或不支持的跳转时提示用户，不伪装完成。

验证包含 Flutter 静态检查、Flutter 单元及组件测试、TypeScript 检查、服务端测试和 ARM64 release APK 构建。新增覆盖多电脑存储隔离、首次启动、离线缓存恢复、额度阻塞与恢复、升级导航限制。浏览器原型继续采用模拟数据；真实双电脑网络、Android 安全存储迁移、原生授权及官方登录支付未宣称已通过验收。

## 0.1.10 内测更新

同步后续确认的原型：额度卡使用“用量统计 / 重置额度”，首页固定欢迎区且仅最近列表滚动，移除浏览项目快捷按钮，新增会话与项目页返回首页，状态文字不着色、绿黄红标记连接状态。项目页卡片化、独立新建和详情、手机端显示名称持久化。

用量页额度与可折叠卡片明细使用真实账号数据。重置确认展示全部可用卡并传递所选 creditId；未知结果重试绑定原卡和原幂等编号，服务端持久化绑定防止换卡。旧的未指定卡片操作沿用原行为。所有重置验证仅使用模拟接口，未执行真实额度重置，留给用户手动确认。
