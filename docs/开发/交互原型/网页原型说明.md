# 网页交互原型

入口：[电脑网页原型](web.html)。手机原型保留原有左侧控制、右侧手机布局，并增加网页入口；两者独立演示，不连接真实账号。

## 布局与响应

- 桌面宽度大于 1150：264px 常驻侧栏，主内容居中限宽，会话资料可在右侧展开。
- 851–1150：230px 侧栏，隐藏右侧辅助栏，缩小内容边距。
- 850 及以下：侧栏改为抽屉，顶栏保留电脑状态、新建与更多操作。
- 500 及以下：助手卡片纵向排列图标和文字，项目与用量改成单列，输入区域仍在会话底部。
- 视口控制支持自适应、1440、1280、1024、768、390；尺寸不会超出实际浏览器宽度。内容区独立滚动，输入区域固定在会话布局底部。
- 基础色为黑白灰，语义连接状态和助手图标保留颜色。浅色、深色、键盘焦点、弹窗焦点约束、Escape 与减少动画偏好均有展示。

## 手机／网页功能对照

| 手机流程 | 网页演示入口及行为 |
| --- | --- |
| 会话首页 | 三个助手切换最近四个会话，点击继续；右上角新建 |
| Codex、Hermes、Claude Code 会话 | 分别可选，消息、输入、发送与演示回复、刷新、会话资料 |
| 会话设置 | 重命名、分享、复制 ID、项目移动、归档确认 |
| 侧栏与搜索 | 桌面常驻、窄屏抽屉，按标题搜索，助手／项目／归档筛选表单 |
| 新建会话 | 助手、项目、名称、初始需求，进入所选助手会话 |
| 添加附件 | 照片、视频、文件、目录；加入草稿后可移除 |
| Hermes 专属入口 | 网址校验、提示词片段插入 |
| Codex 专属能力 | 持续目标、计划模式、Sketch、插件：与手机一样标记未接入真实能力 |
| 图片 | 完整主图、侧边缩略图切换、站内放大预览、缩放 |
| 视频 | 本地示例视频、封面、原比例、原生播放控制、全屏 |
| 历史与草稿 | 长会话、跳底箭头、长输入、附件草稿 |
| 批准／拒绝 | 命令折叠、权限范围、一次批准或拒绝、请求结束状态 |
| 回答问题 | 单选、其他回答原位输入、必填校验、提交结束 |
| 安全输入 | 遮挡、显隐、非空校验、提交／取消清空 |
| 工具记录 | 完成、结果未记录、失败及展开记录 |
| 项目管理 | 双列桌面卡片、项目表单、关联会话、项目操作与移除确认 |
| 用量与重置 | 两个额度窗口、恢复时间、重置确认和结果、异常状态 |
| 工作台 | 资料、电脑、通知、外观、诊断、关于、解除配对；子设置关闭返回工作台 |
| 电脑与配对 | 电脑信息、改名、配对表单与演示结果、解除确认 |
| 内置网络 | 状态、授权说明、检测、退出确认；明确浏览器没有 Android 原生授权能力 |
| 通知 | 开关和站内演示提醒 |
| 故障诊断 | 链路检查、展开信息、最近故障、导出示例 JSON |
| 定时任务 | 列表、编辑、时间选择、启用、删除确认 |
| 下载内容 | 图片预览、示例文件列表与下载边界说明 |
| 网页与本地缓存 | 站内网页预览示例，缓存清理范围和演示入口 |
| 异常状态 | 离线、重连、空列表、额度耗尽、额度查询失败、登录失效、超时；保留草稿 |
| 媒体异常 | 图片加载中／失败、视频失败与重试入口 |

网页复用 `details-catalog.js` 的 35 项手机细节用例，页头可切换细节与状态。实际交互与手机共用产品逻辑的开发工作，需在设计确认后落到 React 组件；本次为独立 HTML/CSS/JS 设计原型，未替换 4310 正式网页。

## 演示边界

数据仅用于设计检查。消息发送返回本地演示回复，真实配对、网络授权、附件上传、任务调度、额度重置、插件调用及账号修改不会发生。安全输入不存储。诊断导出的是标记 `demo: true` 的合成记录。设置仅用于本次演示。功能入口完整展示不等于服务端集成已经完成。
