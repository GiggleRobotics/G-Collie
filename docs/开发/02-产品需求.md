# 产品需求基线

状态：根据当前实现反向整理，供确认与后续迭代使用。日期：2026-10-23。

## 目标与用户

面向已经在电脑使用 Agent 的个人开发者，在离开电脑时，通过手机继续查看、发送和控制原来的会话。核心价值是保持电脑、项目和会话的连续性。

当前形态：Android Flutter 客户端 + 自托管电脑服务 + Web 管理界面。iOS、多用户组织、公共云托管、计费平台不在本轮既有范围内。

## 角色与权限

| 角色 | 允许的行为 |
| --- | --- |
| 电脑管理设备 | 本机初始化、配对和撤销、服务及连接管理 |
| 控制设备 | 在服务端授权和助手支持范围内创建、发送、停止、审批等 |
| 只读设备 | 查看授权内容；服务端拒绝发送、目录写入、重置卡消费等写操作 |

入网与设备配对相互独立。网络连通后仍需配对；模型账号和密钥保留在电脑，不要求手机输入模型 API Key。

## 功能与验收条件

| ID | 需求 | 可观察的验收条件 |
| --- | --- | --- |
| R01 | 连接与配对 | 有效地址和码可进入工作台；重启保留有效授权；过期或撤销后回到配对流程，并说明原因 |
| R02 | 查找原会话 | 可搜索、按助手/项目筛选并打开对应历史；切换会话后不混入旧请求的返回内容 |
| R03 | 新建会话 | 助手和项目均选定后才能进入草稿；首次发送才创建真实会话；取消设置不产生后端会话 |
| R04 | 项目管理 | 选择电脑已有目录或新建目录后项目可再次找到；只读设备无法创建目录；非法路径由服务端拒绝 |
| R05 | 发送与停止 | 普通发送能呈现真实回复；支持的助手执行中可追加；停止绑定当前轮次；超时不自动重复提交 |
| R06 | 过程展示 | 工具默认摘要、可展开实际输入和结果；缺失结果不伪造成功，缺失公开思考摘要不补造内容 |
| R07 | 附件 | 三助手提供统一入口；照片/文件单个 10 MB、视频 100 MB；展示上传进度和失败原因；视频说明仅分析最多 6 帧 |
| R08 | 文件阅读 | 支持类型在 App 内阅读；图片可缩放，PDF 可翻页；可下载原件；删除、过期、撤销授权时可识别失败 |
| R09 | 用量 | 三助手独立切换；日/月、项目、会话、模型按来源呈现；缺失显示未返回，不能补零或跨口径合计 |
| R10 | Codex 重置卡 | 显示真实卡片信息；确认当前账号后才能消费；取消不消费；未知结果重试沿用同一操作编号 |
| R11 | 审批与问题 | 只展示上游实际允许的选项；只读无法提交；未支持类型引导回电脑处理 |
| R12 | 分享与通知 | 支持范围内可生成可撤销只读快照；通知不包含聊天正文；点击进入正确会话；无权限时说明限制 |

这些是验收要求，不表示所有场景已验收通过；实际记录见 [当前工作](01-当前工作.md)。

## 助手能力边界

| 能力 | Codex | Hermes | Claude Code |
| --- | --- | --- | --- |
| 查看历史 | 支持 | 支持 | 支持 |
| 新建 / 继续 / 停止 | 依赖桌面控制与协议可用 | 依赖唯一可识别本机后端 | G-Collie 创建的会话支持；终端创建的仅查看 |
| 执行中追加 | 有真实验收记录 | 有真实验收记录 | 不作为已验收能力承诺 |
| 原生图片 / 视频抽帧 | 已有真实模型验收 | 已有真实模型验收 | 已有真实模型验收 |
| 手机审批 / 问题 | 上游支持的类型 | 上游支持的类型 | 尚未接入手机审批 |
| 分享 / 推送 | 支持但有运行与网络限制 | 支持但有运行与网络限制 | 尚未接入 |
| 用量 | 账号与本机分开 | 本机累计及采集值 | 本机主会话及子代理日志 |
| 额度重置卡 | 有入口，实际消费未验收 | 不适用 | 不适用 |

## 通用交互要求

- 页面明确区分加载、空数据、失败、只读、执行中和状态未知。
- 断线后展示状态未知并禁用不安全的会话操作；恢复时重新同步。
- 输入文字或附件非空显示发送；执行中输入为空显示停止；各按钮还受权限和助手能力限制。
- 请求结果未知时先核对状态，不自动重放写请求；重复操作编号不得重复创建会话或消费卡片。
- 不展示内部消息包装、原始隐藏思考或模型账户凭据。
