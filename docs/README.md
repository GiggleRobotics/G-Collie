首次使用：电脑安装启动 → 配置可访问地址 → 生成配对码 → 手机安装并配对 → 使用专用测试会话验证。

电脑端、手机端及内置远程连接手册已按电脑 0.3.32／Android 0.1.47（49）更新，图文和发布稿材料已准备，尚未发布。

本轮正式手机及两台服务器已完成相关验证，当前 VPN 环境冷启动恢复；具体范围与未测边界见 [验证记录](开发/06-版本发布记录.md)。
