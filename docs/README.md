# G-Collie 使用说明

版本：0.2.0 开发者内测版 · 更新：2026-10-19

- [0.3.0 内置远程连接](内置远程连接.md)：电脑和手机内置 Tailscale 的登录、配对和网络权限。
- [电脑端使用说明](电脑端使用说明.md)：DEB 安装、后台服务、Agent 接入、Tailscale、设备配对、分享、备份升级和故障处理。
- [手机端使用说明](手机端使用说明.md)：APK 安装、连接地址、配对、查找和新建会话、发送停止、用量、分享与通知限制。

第一次使用的顺序：**电脑安装启动 → 配置手机可访问的地址 → 电脑生成配对码 → 手机安装并配对 → 用测试会话验证操作**。

当前状态：电脑安装与配对权限验证通过；测试手机仍需允许系统安装，尚未完成 APK 实机验收。说明中未将待验收项目视为已经通过。
