## 可直接发布正文（最终验证后使用）

最近做了一个自己会用的小工具：G-Collie 🐾

它做的事很简单：电脑继续跑 Agent，手机查看进展、发补充要求，操作原来的会话。不是在手机里重新开一个不相干的聊天，也不用把整个项目拷来拷去。

现在可以接入 Codex、Hermes 和 Claude Code。首页选助手、找最近会话；想开始新任务就点新建，选助手和项目，直接写第一条消息，不用先想会话名。

我最常用的是这些：

① 离开电脑后继续看回复和工具过程。
② 执行中补充要求，或按当前会话能力停止这一轮。
③ 在已支持的请求里批准／拒绝、回答问题；普通模式 Hermes 安全输入有遮罩，也能取消；上游 managed／安全工作模式未提供的能力仍不可用。
④ 添加照片和文件，查看会话里的资料。
⑤ 保存多台电脑，按需要切换。

连接分两步：先让电脑和手机各自授权加入同一个私网，再用 G-Collie 的六位码配对。只有终端的服务器也能执行 `g-collie pair` 取码，不需要服务器有桌面浏览器。网页和手机各自配对。

有几件事提前说清楚：任务在来源电脑执行，电脑需要在线；当前 VPN 环境已验证冷启动恢复连接，其他网络和长后台还待验证；三个 Agent 的能力并不完全相同；当前 G-Collie 的安全删除只适配满足条件的新版 Hermes，Codex／Claude 暂未适配。未知结果先刷新核对，不连点重发。后台提醒还受手机系统和网络影响，不承诺全天候在线。

目前提供 Linux amd64 电脑端和 Android 客户端；Windows、iOS、macOS 暂无本轮已验证安装包。安装、连接和排错已经整理进 README 与双端使用说明。公开下载入口仍在准备，实际获取方式以项目页面为准。

希望它能让离开电脑这件事轻松一点。后续先把已有功能和异常状态做好，再慢慢补能力。
