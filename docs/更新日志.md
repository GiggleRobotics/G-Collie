# G-Collie 更新日志

本页记录用户可见的变化。电脑服务与 Android 客户端分别编号。安装包、签名与校验文件随对应版本分发。[发行说明](../RELEASE.md) · [历次开发与验证记录](开发/06-版本发布记录.md)

## 未发布

以下改动在 v0.3.35 之后的源码中，部分曾单独部署到测试设备。公开发行页仍提供 v0.3.35 的原始文件。

- 网页和 Android 的新会话草稿会区分正在发送、等待电脑确认和确定未发送。未收到明确结果时可以刷新原请求的回执，草稿保留正文和附件。电脑明确指出损坏图片时，可以移除或更换这张图片后再手动发送。
- Android 在已有会话中发送超时，切换到另一会话再回来，手动重试相同内容沿用原发送编号。迟来的回执只消费原会话本次发送的附件。
- 窄屏网页可从项目、用量、定时、下载、诊断和服务端管理页直接打开会话列表，返回会话或首页。
- Codex 桌面接入适配会话流协议 v13，保留 v11。Hermes 会话中助手明确引用的本机媒体目录图片可正常读取。
- Codex、Hermes 和 Claude Code 的历史消息共用会话图片读取规则。网页版可从原工具记录打开图片；网页与 Android 支持在消息中查看远端图片附件并打开大图。

## 0.3.35 · 2026-11-17

首次公开发行，Linux／网页 **0.3.35**，Android **0.1.51**（arm64 构建 2058，x86_64 构建 4058）。

- 在 Linux 电脑部署服务，Android 或浏览器配对后查看与操作原有会话。无图形桌面的服务器可通过 Codex app-server 控制，内部子 Agent 会话从普通列表过滤。
- 修复 Hermes 轮次控制兼容性，支持满足原生条件的会话删除。图片预览、切网后的会话同步与横屏侧栏滚动得到改进。
- 提供 Linux amd64 DEB、Android 双架构正式签名 APK、旧内测 arm64 同签升级包、对应源码及校验文件。[v0.3.35 下载](https://github.com/GiggleRobotics/G-Collie/releases/tag/v0.3.35)

## 0.3.3 · 2026-10-19

内测版在输入框“＋”中加入照片与文档／代码／日志附件。每条消息最多五个普通附件，单个不超过 10 MB，在来源电脑保留七天。上传后可预览、移除，手动发送后才进入会话。

Codex 图片使用原生图片输入，其他文件作为电脑本机的附件路径提供。Hermes 当时支持文件引用，图片入口仍待验证。Android 使用系统照片／文件选择器。该版本尚在排查移动数据切网后的连接超时。

## 0.3.2 · 2026-10-19

- 电脑与 APK 内置 Tailscale，服务端口统一为 4310。手机可发现已入网的电脑，配对页面可将地址和配对信息交给 APK。
- 连接前验证电脑服务并提示地址、协议或端口错误。内置网络进程异常后可恢复。
- Android 增加任务结束、待处理、持续断线和授权失效提醒。点击通知打开对应会话，可手动停止提醒。最近打开的 30 个会话持久关注，服务重启后恢复。
- Linux 新增 `g-collie doctor` 和 `g-collie backup`。卸载用户服务时保留应用数据。

此版本为早期内测。后台提醒受通知权限、省电和强制停止影响。当时的记录未覆盖实体手机移动数据跨网。
