# G-Collie 更新日志

最新内部更新及问题修复见 [版本发布记录](开发/06-版本发布记录.md)，本页保留早期版本记录。

## 0.3.2 · 2026-10-19

- 电脑与 Android APK 内置 Tailscale，正式服务统一使用 4310。
- 手机发现已入网的 G-Collie 电脑；配对页可直接打开 APK，自动带入电脑地址和配对信息。
- 连接前验证 G-Collie 服务，错误地址、协议或端口有明确提示；网络进程异常后自动恢复。
- APK 原生任务提醒：任务结束、需要处理、持续断线和授权失效；常驻通知可停止提醒，点击事件回到对应会话。
- 最近打开的 30 个会话持久关注，电脑服务重启后恢复；首次载入与断线期间不推断完成。
- Linux 增加 `g-collie doctor`、`g-collie backup`；移除用户服务会清理单元文件并保留应用数据。

当前为开发者内测。Android 后台提醒需要通知权限，受前台服务时长、省电和强制停止影响。实体手机与移动数据跨网验收尚待完成，不承诺全天候提醒。

## 0.3.3 · 2026-10-19

输入框“＋”支持添加照片、上传文档/代码/日志，选中后显示附件预览，可移除后再发送。每条最多 5 个，每个不超过 10 MB，文件在电脑私有目录保留 7 天，上传到电脑不代表已经发送，点击发送后才进入 Agent 会话。

Codex 图片使用原生图片输入，其他文件以电脑本机附件路径提供给 Agent；Hermes 先支持文件引用，图片入口待验证。Android APK 使用系统文件/照片选择器，不要求读取整个相册的权限。

移动数据切网后的连接超时仍在定位，本版本未宣称修复跨网问题。
