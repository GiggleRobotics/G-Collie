# 当前能力与端差异

下表列出公开版电脑／网页 **0.3.36** 与 Android **0.1.52** 的操作入口和使用条件。两端连接同一台电脑，能看到历史后，还需来源助手已登录、有可用控制接口，才能在原会话中发送。[公开版下载](https://github.com/GiggleRobotics/G-Collie/releases/tag/v0.3.36) · [本版变化](#本版交互变化)

状态口径：已实现表示已有代码和操作入口，部分实现表示有来源或环境限制，尚未验证表示没有该场景的当前证据。三助手不共享同一组控制能力；服务连通、历史可读、Agent 登录与实时控制分别核对。

| 功能 | Android | 电脑网页 | 约束 |
| --- | --- | --- | --- |
| 三助手历史 | 已实现，按来源读取，隐藏内部子 Agent | 同左 | 读取当前电脑服务用户的原记录，不跨电脑自动同步；来源缺失／无权限需分别排查 |
| Codex 新建、发送、追加、停止 | 部分实现 | 同左 | 有桌面接口时保留原桥；无桌面时使用本用户 app-server，优先现存安全 daemon。原生 CLI／登录可用，历史需显式恢复；独立后端遇其他 Codex 进程占用则拒绝接管 |
| Hermes 新建、发送、追加、停止 | 部分实现 | 同左 | 依赖兼容的本机 gateway／后端、会话加载与当前轮次；停止只针对当前轮，已排队追加可能随后执行 |
| Claude Code 新建、发送、停止 | 部分实现 | 同左 | 需 CLI 安装、登录／API 配置；G-Collie 创建的会话才具相应控制链，外部终端历史只读。来源电脑须已有可用登录或 API 配置 |
| 会话删除 | 部分实现 | 同左 | 仅满足原生资格的新版 Hermes，含同源压缩／重置历史及对应 G-Collie 分享、提醒；不删项目文件。Codex／Claude 安全删除未适配。历史 unknown 由服务器重新核资格，执行中／离线／只读禁删，删除结果未知不重放 |
| 首页助手与新建 | 已实现 | 已实现，含首页文字入口 | 选择助手／项目后进入草稿，首发才创建，名称自动生成；取消设置不创建任务 |
| 结构化批准、单选／多选回答 | 部分实现 | 同左 | 只适配原生已知请求；校验请求、轮次和连接代际，只提交后端允许的决定，未知类型回原生端；不自动批准真实任务 |
| Hermes 安全输入与取消 | 部分实现 | 同左 | 普通会话须上游提供 sudo／secret 回调；managed／safe_mode／ignore_user_config 模式可能不提供。遮罩输入不作为聊天发送；结果未知按请求持久锁定，不换编号重发 |
| 图片／视频浏览 | 会话内左右滑动、缩放、切换视频 | 左右滑动、方向键、翻页按钮 | 仅当前会话已加载历史中引用的媒体；切走暂停 |
| 照片、视频、文件 | 部分实现 | 部分实现 | 选择、上传、模型读取、历史预览是不同环节；依赖来源与模型视觉能力。切会话、离线或降权丢弃过期选择；普通附件数量／大小限制与视频流程分开 |
| 电脑目录 | 浏览选择／路径引用 | 路径引用 | 不上传整个目录 |
| Hermes 网址／片段 | 支持 | 支持 | 片段存在本设备／浏览器，不跨端同步 |
| 图片剪贴板 | 点击后读取 | 浏览器支持且授权后读取 | 不自动读取；最多10MB，类型校验 |
| Codex 持续目标 | 原生接口 | 原生接口 | 依赖本机版本；不保证模型长期自主运行 |
| Codex 计划模式 | 按后端部分支持 | 同左 | 桌面桥原生轮次设置；终端桥尚未验证协议，隐藏并拒绝该模式 |
| Codex 插件技能 | 列出已启用本地技能并选择 | 同左 | 原生 skill 输入；不自动安装或授权远程插件 |
| Sketch | 绘制／撤销／PNG附件 | 绘制／清空／PNG附件 | 手动加入草稿，不自动发送 |
| 用量及重置 | 支持 | 支持 | 数据失败不伪装零额度；不为测试消费卡片 |
| 定时任务 | 支持 Codex | 支持 Codex | 电脑持续运行；未知结果不重放 |
| 会话缓存与草稿 | 支持 | 当前浏览器草稿 | 手机已缓存历史可离线查看；未下载视频离线不可播放 |
| 下载 | App 内记录与打开 | 浏览器保存 | 两端下载记录不互相同步 |
| 私有网络 | 部分实现：内置节点／系统网络 | 电脑网络／服务配置 | 入网与设备配对独立；已在一个实体手机私网环境验证两次冷启动恢复；网络可达性依赖访问策略和电脑状态 |
| 设备配对、撤销、手机日志 | 连接及上传／导出 | 管理端集中管理 | 沿用配对凭据和角色授权 |
| 深浅主题、横屏／窄窗口 | 已实现，横屏低高度侧栏已真机复验 | 已实现 | 400dp 侧栏已覆盖组件滚动／搜索与横屏真机；保留品牌色与语义状态色，其他设备／字号不据此外推 |

## 本版交互变化

| 场景 | 本版行为 |
| --- | --- |
| 网页／Android 新会话首发 | 正在发送和等待回执期间保留正文与附件；可按原请求查结果。明确失败可编辑，准确定位的坏图需移除或更换后再手动重试。旧电脑未返回具体附件时显示通用错误。 |
| Android 已有会话的迟到回执 | 在运行中的工作区，切换会话后手动重试相同内容沿用原编号。只消费对应发送的附件。进程回收后恢复待确认发送尚未验证。 |
| 窄屏网页辅助页 | 项目、用量、定时、下载、诊断、服务端管理页可直接打开会话列表；宽屏沿用常驻侧栏。 |

版本间的其他兼容性修复见[更新日志](更新日志.md)。

## 历史专项证据补充（版本以各条标注为准）

- 专用正式手机 QA 已核对 Hermes 执行中追加、当前轮停止、批准一次／拒绝、问答，以及普通会话 secret／sudo 取消和假值提交；后端原生记录与消费结果对应。sudo 使用不委派命令的隔离 shim，不代表真实提权测试。测试值未进入聊天／G-Collie 操作记录，唯一测试环境变量已精确清理。
- 图片已有正式手机附件保留／发送及原生暂存证据；辅助视觉请求与随后主模型请求需分开核对，不把主请求无图误判为整条链路无图，也不承诺所有模型看图。具体像素／provider 证据以发布记录为准。
- 桥协议单测、正式网页连接隔离 gateway 的浏览器测试、Flutter 组件测试与网络核心普通／race 测试分别记录；不得合称所有功能真机通过。电脑 0.3.31／Android 0.1.46 已完成当时的安装及记录专项；未测范围继续保留。
- Android-only TLS 握手时限从上游 5 秒放宽至 15 秒，保留父级 deadline／取消及证书校验。正式 APK 内网络库 build ID 与新构建一致，临时 Tailscale replacement 和 BSD 许可／修改声明已独立验包。当时使用的手机在既有 VPN 环境两次冷启动：一次 uptime 约 9 秒已 Running、timeout 计数 0；另一次从 Flutter 启动约 31 秒显示来源电脑在线及原 3 个会话，采样未见 NoState／Open failed。这是两次当前环境结果，不代表任何 VPN 或长时网络均稳定。
- 后台通知、长期锁屏、最低 Android 版本、持续切网、真实额度重置和未登录 Agent 的执行能力仍缺少覆盖所有环境的验证。

组件、接口和本机回归不等同于所有机型和网络的长时间验收。真实额度耗尽／恢复、账号重置、后台通知、间歇断网／锁屏与特定外站兼容继续按专项记录。未知请求类型明确提示回到助手原生端处理，不绕过授权。
