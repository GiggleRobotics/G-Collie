# 当前能力与端差异

2026-11-04，电脑／网页 0.3.16，Android 0.1.27（2029）。开发者内测，实际安装与验收证据见 [开发与测试](开发/2026-11-04-开发与测试.md)。

| 功能 | Android | 电脑网页 | 约束 |
| --- | --- | --- | --- |
| 三助手历史、发送、停止 | 支持 | 支持 | 使用原会话；只读、归档及离线禁写 |
| 首页助手最近四会话 | 支持 | 支持 | 切助手不创建会话；新建在右上角 |
| 结构化批准、单选／多选回答、安全输入 | 支持 | 支持 | 只提交后端允许的决定，不自动批准用户任务 |
| 图片／视频浏览 | 会话内左右滑动、缩放、切换视频 | 左右滑动、方向键、翻页按钮 | 仅当前会话已加载历史中引用的媒体；切走暂停 |
| 照片、视频、文件 | 支持 | 支持 | 附件大小与格式限制保留 |
| 电脑目录 | 浏览选择／路径引用 | 路径引用 | 不上传整个目录 |
| Hermes 网址／片段 | 支持 | 支持 | 片段存在本设备／浏览器，不跨端同步 |
| 图片剪贴板 | 点击后读取 | 浏览器支持且授权后读取 | 不自动读取；最多10MB，类型校验 |
| Codex 持续目标 | 原生接口 | 原生接口 | 依赖本机版本；不保证模型长期自主运行 |
| Codex 计划模式 | 原生轮次设置 | 原生轮次设置 | 下一轮生效，执行中不改变当前轮 |
| Codex 插件技能 | 列出已启用本地技能并选择 | 同左 | 原生 skill 输入；不自动安装或授权远程插件 |
| Sketch | 绘制／撤销／PNG附件 | 绘制／清空／PNG附件 | 手动加入草稿，不自动发送 |
| 用量及重置 | 支持 | 支持 | 数据失败不伪装零额度；不为测试消费卡片 |
| 定时任务 | 支持 Codex | 支持 Codex | 电脑持续运行；未知结果不重放 |
| 会话缓存与草稿 | 支持 | 当前浏览器草稿 | 手机已缓存历史可离线查看；未下载视频离线不可播放 |
| 下载 | App 内记录与打开 | 浏览器保存 | 两端下载记录不互相同步 |
| 私有网络 | App 内网络／系统 VPN | 电脑网络／服务配置 | 原生网络授权不由网页伪造 |
| 设备配对、撤销、手机日志 | 连接及上传／导出 | 管理端集中管理 | 沿用配对凭据和角色授权 |
| 深浅主题、横屏／窄窗口 | 支持 | 支持 | 保留品牌色与语义状态色 |

## 验证口径

组件、接口和本机回归不等同于所有机型和网络的长时间验收。真实额度耗尽／恢复、账号重置、后台通知、间歇断网／锁屏与特定外站兼容继续按专项记录。未知请求类型明确提示回到助手原生端处理，不绕过授权。
